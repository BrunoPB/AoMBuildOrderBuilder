# Security

> **Português:** achou uma falha de segurança? Não abra uma issue pública: use o botão abaixo ou mande um e-mail.

The app is a static site: no server, no accounts, and builds stay in your browser (`localStorage`). The parts that handle outside input are build imports (files and share links) and the GitHub workflow that checks proposed builds.

To report a vulnerability, **do not open a public issue**. Use [Report a vulnerability](https://github.com/BrunoPB/AoMBuildOrderBuilder/security/advisories/new) (GitHub's private reporting) or e-mail [brunopenabaeta@gmail.com](mailto:brunopenabaeta@gmail.com). Say what is affected and how to reproduce it; you will get an answer as soon as possible.

Only the latest version (the `master` branch and the published site) gets fixes.
