# Atlanteans: actions per major god

Source: the installed game, build 19.17020 (extracted `gameplay\*`, string tables, and the modding guide shipped with the game, `BANG_Documentation\Data documentation\AoMRT_Comprehensive_Core_Data_Guide_Extended.pdf`, for what the tags mean), unless a row says otherwise. Paths are relative to `gameplay\`. The data is in `actions.json`. "BO" means the action matters for a build order (`buildOrder: true`). Web sources (fan wiki, forum, aomr-analyzer) are only used where the files say nothing, and are marked.

How I searched: `ArchaicAgeAtlantean` / `ArchaicAgeKronos|Oranos|Gaia` and the Classical/Heroic/Mythic age techs (`TechStatus`, `CommandAdd`, `ActionEnable`, `TransformUnit`); every Atlantean unit's and building's `<command>`, `<transformcommand>` and protoactions in proto.xml; `proto_unit_commands.xml`; `unit_transform.xml`; `abilities\abilities.xml` + `atlantean.abilities`; the tactics files; `major_gods.xml` (`timeshifting`, `terraincreeps`); `terrain_unit_effects.xml`; every techtree effect that targets a `HeroPromotion` / `HeroInfantry` / `HeroCavalry` tech type.

Atlanteans have **no** empower or convert commands. Player-issued god-specific commands: **hero promotion** (all gods), **Time Shift** (Kronos), **Sky Passage Teleport** (Oranos). Everything else god-specific is passive.

## Common to all Atlantean gods: hero promotion

`Promover a Herói` / `Promote to Hero` (`STR_TRANSFORM_TO_HERO`). Enabled from the Archaic Age by `ArchaicAgeAtlantean` (`TechStatus active` of the ten `…ToHero` techs). Each promotion is a tech (`techtype HeroPromotion`) researched **on the unit**: cost paid when it starts, then `researchpoints` 7 s. The hero protos have `UnitTransformFree`, so the hero's own proto cost is not charged. Pop never changes. `unit_transform.xml` links each pair.

**Does the unit keep working?** Not in the files. Fan wiki (Age of Empires Series Wiki, Atlanteans): the unit is _completely immobile during the transformation_ and only becomes a hero at the end. A patch note fixed queuing movement for a Citizen while it is promoting. → `keepsWorking: false`, confidence medium.

No other "convert to hero" variant exists: the only other hero sources are Gaia's start (2 Citizen Heroes) and Sons of the Sun.

## Open points

- Whether a unit keeps working while promoting: only from the fan wiki ("immobile"). Please measure.
- Sky Passage Teleport cooldown: not in the files or in any web source found.
- Time Shift: whether the old building keeps training/researching, whether Temporal Scaffolding affects it, and the exact duration (guide semantics, not measured); whether the cost ratio also applies to favor.
- Poseidon's Secret promotion discount (Turma, Contarius) is not in `atlanteans.json` yet.
